## 1. 产品全景

### 1.1 产品模块地图

```
词境（WordScape）
│
├── 【词库中心】      管理所有词汇表（内置 + 自定义）
│
├── 【课程中心】      基于词库生成的精读课程
│   └── 【阅读器】   单篇文章的阅读交互
│
├── 【词典】         全局词汇数据库（查词、生词本）
│
├── 【学习统计】     进度、连续天数、词汇掌握度
│
├── 【设置】
│   ├── 模型配置     OpenAI 兼容接口配置
│   ├── 账号与会员
│   └── 偏好设置     字体大小、中文显示方式等
│
└── 【落地页】       未登录用户的产品介绍页
```

### 1.2 核心概念定义

| 概念 | 定义 |
|------|------|
| **词库（Vocabulary Set）** | 一组目标词汇，可来自内置或用户导入 |
| **课程（Course）** | 基于一个词库 AI 生成的全套精读文章集合 |
| **文章（Article）** | 课程中的单篇精读故事，约 1000 词 |
| **目标词（Target Word）** | 文章中来自词库的词汇，会高亮显示 |
| **生词本（Wordbook）** | 用户手动收藏的词汇集合 |

## 2. 功能模块详细规格

---

### 2.1 模块一：词库中心

#### 功能概述
用户在此管理所有词汇来源，是整个产品的数据入口。

#### 2.1.1 内置词库

系统预置以下词库，用户一键选用，无需导入：

| 词库 ID | 词库名称 | 词汇量 | 预计篇数 | 适用人群 |
|---------|---------|--------|---------|---------|
| `builtin_junior` | 初中英语词汇 | 1,500 | 15 篇 | 初中生 |
| `builtin_senior` | 高中英语词汇（新课标） | 3,500 | 35 篇 | 高中生 |
| `builtin_cet4` | 大学英语四级词汇 | 4,000 | 40 篇 | 大学生 |
| `builtin_cet6` | 大学英语六级词汇 | 6,000 | 60 篇 | 大学生 |
| `builtin_kaoyan` | 考研英语核心词汇 | 5,500 | 55 篇 | 考研生 |
| `builtin_ielts` | 雅思核心词汇 | 4,500 | 45 篇 | 雅思备考 |
| `builtin_toefl` | 托福核心词汇 | 4,000 | 40 篇 | 托福备考 |

**内置词库的特殊权益**：
- 前 5 篇文章免费（免登录可读）
- 已完成人工质检，质量有保障
- 未来可随官方词库更新自动同步

#### 2.1.2 自定义词库导入

**导入方式 A：文本粘贴**

```
支持格式（以下任一）：
  每行一词：
    abandon
    absolute
    academic

  逗号分隔：
    abandon, absolute, academic, access

  带释义（系统提取词汇部分）：
    abandon v. 放弃
    absolute adj. 绝对的
```

**导入方式 B：文件上传**

```
支持格式：
  .txt   纯文本，每行一词或逗号分隔
  .csv   第一列为单词（自动识别）
  
文件大小限制：≤ 1MB
单次导入词汇上限：10,000 词
```

**导入后的处理流程（系统自动）：**

```
Step 1  清洗
        - 去重（大小写不敏感）
        - 去除首尾空格
        - 过滤非英文字符词条
        - 提示用户：「共导入 XX 词，过滤无效词条 XX 个」

Step 2  词频标注
        - 查词频数据库，标注每个词的频率等级（1–5）
        - 用于后续分层法排序

Step 3  话题聚类
        - 调用 AI 将词汇按语义话题自动分组
        - 生成话题标签（校园、职场、科技等）
        - 用于课程章节规划

Step 4  课程规划
        - 计算生成篇数：词汇量 ÷ 100（向上取整）
        - 确定每篇的目标词列表
        - 安排复现词分布

Step 5  展示预览
        - 告知用户：将生成 XX 篇文章，涵盖 XX 个话题
        - 用户点击「开始生成」触发异步任务
```

**自定义词库页面字段：**

| 字段 | 是否必填 | 说明 |
|------|---------|------|
| 词库名称 | 是 | 用户自定义，如「期末复习词汇」 |
| 词汇内容 | 是 | 粘贴或上传 |
| 文章语言难度 | 否 | 初级/中级/高级（影响生成文章的句式复杂度） |
| 故事风格偏好 | 否 | 日常生活 / 职场 / 校园 / 混合（默认混合） |

### 2.2 模块二：课程中心

#### 功能概述
展示用户所有课程（含生成进度），提供文章列表和学习入口。

#### 2.2.1 课程卡片信息

每个课程展示：
- 课程名称（来自词库名称）
- 来源标签（内置官方 / 自定义）
- 总篇数 & 已读篇数
- 整体进度百分比（环形进度条）
- 生成状态（生成中 / 可学习）
- 最近阅读时间

#### 2.2.2 课程内文章列表

文章列表展示（卡片式）：

```
[序号] [话题标签]  [文章标题]
       目标词 XX 个 · 约 X 分钟 · [阅读状态]

阅读状态：
  ○ 未开始
  ◐ 进行中（显示具体进度 XX%）
  ● 已完成
  🔒 未解锁（付费内容）
```

**筛选与排序：**
- 按话题筛选（横向标签栏）
- 按状态筛选（全部 / 未读 / 进行中 / 已读）
- 排序：默认按序号，可切换按话题分组

### 2.3 模块三：阅读器（核心模块）

#### 2.3.1 页面布局

**手机端（< 768px）：**

```
┌────────────────────────┐
│ [←] 话题标签 · 第N篇  [⋯]│  固定顶部导航
│ ████████████░░░ 75%    │  阅读进度条
├────────────────────────┤
│                        │
│  （英文正文区）         │  主阅读区，可滚动
│                        │
├── [中文对照] ──────── [▼]│  底部抽屉，可展开/收起
│  （中文对照区）         │
└────────────────────────┘
│ [◀ 上一篇]  [▶ 下一篇] │  底部固定导航
└────────────────────────┘
```

**PC 端（≥ 1024px）：**

```
┌──────────────┬─────────────┐
│              │             │
│  英文正文区   │  中文对照区  │  左右分栏
│  （60%宽）   │  （40%宽）  │  同步高亮
│              │             │
└──────────────┴─────────────┘
```

#### 2.3.2 文字展示规格

| 属性 | 手机端 | PC 端 |
|------|--------|-------|
| 英文字体 | Lora / Georgia（衬线体） | 同左 |
| 中文字体 | PingFang SC / Noto Sans SC | 同左 |
| 英文正文字号 | 17px | 18px |
| 中文对照字号 | 15px | 16px |
| 行高 | 1.85 | 1.9 |
| 段落间距 | 1.2em | 1.4em |
| 最大内容宽度 | 100% | 680px |

#### 2.3.3 目标词高亮

```
显示规则：
  目标词（词库中的词）→ 琥珀黄底色下划线标注
  普通词 → 无标注

点击行为（目标词）：
  单击 → 触发词典卡片弹层

点击行为（非目标词）：
  双击 → 也触发词典卡片弹层（临时查词，不计入生词本）
  （手机端：长按触发）
```

#### 2.3.4 句子交互

```
触发方式：单击英文句子的任意位置（非单词双击）
效果：
  1. 该句英文高亮背景
  2. 中文对照区对应句子同步高亮
  3. TTS 朗读该句英文
  4. 朗读时逐词动态高亮（跟读效果）

TTS 参数：
  语速：0.85x（略慢于正常语速，便于跟读）
  音色：美式英语（可在设置中切换英式）
  实现：优先使用 Web Speech API，降级到配置的 TTS 服务
```

#### 2.3.5 词典卡片弹层

**触发**：点击目标词 / 双击普通词

**弹层位置逻辑**：
```
若点击位置在屏幕上半部 → 卡片出现在词语下方
若点击位置在屏幕下半部 → 卡片出现在词语上方
若空间不足 → 从屏幕底部以抽屉形式弹出
```

**卡片内容规格**：

```
┌──────────────────────────────┐
│  abandon          /əˈbændən/ │  词 + 音标
│                          [🔊]│  发音按钮
│  v. 放弃；遗弃；停止          │  词性 + 释义（最多3条）
│  ──────────────────────────  │
│  词根：band（绑）→ 解除绑定   │  词根（可折叠，默认收起）
│  ──────────────────────────  │
│  The team abandoned the      │  例句1（英文）
│  project due to lack of      │
│  funding.                    │
│  团队因资金不足放弃了该项目。  │  例句1（中文）
│  ──────────────────────────  │
│  [+ 加入生词本]  [× 关闭]    │  操作按钮
└──────────────────────────────┘
```

**字段规格**：
| 字段 | 内容 | 是否必须 |
|------|------|---------|
| 单词 | 原形 | 是 |
| 音标 | IPA 国际音标（美式） | 是 |
| 发音 | TTS 朗读按钮 | 是 |
| 词性+释义 | 最多展示 3 条常用义 | 是 |
| 词根词缀 | 简短说明，默认折叠 | 否（能生成则展示） |
| 例句 | 2 句，含中文翻译 | 是 |
| 加入生词本 | 按钮，已收藏则变为「已收藏✓」 | 是 |

**关闭方式**：点击卡片外任意区域 / 点击 × 按钮

#### 2.3.6 阅读进度保存

```
自动保存时机：
  - 每滚动一定距离自动记录位置
  - 退出页面时保存

下次进入：
  - 弹出提示「上次读到第 XX 段，是否继续？」
  - 选「继续」→ 滚动到上次位置
  - 选「从头开始」→ 回到顶部
```

## 3. 核心用户流程

### 3.1 新用户首次使用流程

```
访问首页
  ↓
浏览产品介绍（了解学习方法）
  ↓
点击「开始学习」
  ↓
选择词库
  ├── 选内置词库（如：四级词汇）→ 直接进入课程（已预生成）
  └── 选自定义导入 → 粘贴/上传词汇 → 配置生成参数 → 等待生成
  ↓
进入课程文章列表
  ↓
点击第 1 篇文章（免费）
  ↓
阅读体验：点词查义 → 点句朗读 → 中文对照
  ↓
完成第 1 篇，提示进度 & 引导继续
  ↓
读至第 5 篇结尾，触发付费引导
```

### 3.2 自定义词库生成流程

```
进入词库中心 → 点击「+ 新建词库」
  ↓
填写词库名称
  ↓
选择导入方式
  ├── 粘贴文本 → 粘贴框输入
  └── 上传文件 → 选择 .txt/.csv
  ↓
（可选）设置文章难度 & 风格偏好
  ↓
点击「预览课程」
  ↓
系统展示：清洗后词汇数、预计生成篇数、话题分布预览
  ↓
确认 → 点击「生成课程」
  ↓
提交异步任务 → 展示生成进度（进度条 + 已完成篇数）
  ↓
生成完成 → 推送通知（浏览器通知 / 站内消息）
  ↓
进入课程开始学习
```

### 3.3 日常学习流程

```
打开 App
  ↓
首页展示：今日建议阅读 + 上次进度
  ↓
点击继续阅读 / 选择新文章
  ↓
阅读文章（点词/点句交互）
  ↓
完成文章 → 展示本篇学到的目标词列表（打卡卡片）
  ↓
可选：收藏未掌握词汇到生词本
  ↓
点击下一篇 / 退出
```

## 5. 内容生成规格

### 5.1 文章生成 Prompt 设计原则

系统调用 AI 生成文章时，Prompt 需包含以下约束：

```
硬性约束（必须满足）：
  ① 文章总词数：900–1100 词
  ② 目标词（词库词汇）出现数量：90–110 个
  ③ 每个目标词只使用一次（避免同词重复堆砌）
  ④ 目标词使用原形或合理变形（如 abandon → abandoned）
  ⑤ 体裁：叙事故事（有人物、有情节、有场景）
  ⑥ 非目标词以 A2–B1 级常见词为主，保证可读性
  ⑦ 段落数：8–12 段，每段 3–6 句
  ⑧ 输出格式：JSON（含英文正文、中文翻译、目标词位置）

软性约束（尽量满足）：
  ① 故事有完整的起承转合
  ② 目标词在自然语境中出现，不生硬
  ③ 话题与词汇语义场一致
  ④ 人物和场景在同一课程内保持一定连贯性（系列故事感）
```

### 5.2 输出数据格式（AI 返回）

```json
{
  "article": {
    "title": "The Research Proposal",
    "topic": "校园生活",
    "paragraphs": [
      {
        "id": 1,
        "en": "Sarah stared at her blank computer screen...",
        "zh": "Sarah 盯着她空白的电脑屏幕……",
        "sentences": [
          {
            "id": "1-1",
            "en": "Sarah stared at her blank computer screen.",
            "zh": "Sarah 盯着她空白的电脑屏幕。",
            "target_words": ["blank"]
          }
        ]
      }
    ],
    "target_words_used": [
      {
        "word": "blank",
        "form_used": "blank",
        "sentence_id": "1-1",
        "char_offset": 20
      }
    ]
  }
}
```

### 5.3 词典数据生成

每个目标词的词典数据在首次遇到时生成（懒加载），或在课程生成阶段批量预生成：

```json
{
  "word": "abandon",
  "phonetic": "/əˈbændən/",
  "pos": "v.",
  "definitions": [
    { "meaning": "放弃；遗弃", "en": "to leave someone or something permanently" },
```

### 5.4 生成质量校验

每篇文章生成后，系统自动进行以下校验：

| 校验项 | 规则 | 不通过处理 |
|--------|------|----------|
| 词数检查 | 900–1100 词 | 自动重新生成 |
| 目标词覆盖率 | ≥ 90% 指定词汇出现 | 自动重新生成 |
| 目标词密度 | 8%–12% | 自动重新生成 |
| 格式合法性 | 合法 JSON，字段完整 | 自动重新生成 |
| 最大重试次数 | 3 次 | 标记为「生成失败」，用户可手动重试 |

## 6. 模型配置规格

### 6.1 设计理念

系统对接任意 OpenAI 兼容接口，用户在设置中自行配置。这样做的好处：
- 用户可接入 OpenAI、DeepSeek、月之暗面、阿里 DashScope、本地 Ollama 等任意服务
- 平台本身不需要承担 API 调用成本（C 端用户自带 Key）
- 符合国内用户使用习惯（不同用户有不同的可用模型）

### 6.2 配置项

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| Base URL | API 接口地址 | `https://api.openai.com/v1` |
| API Key | 鉴权密钥 | `sk-xxxxxxxx` |
| 模型名称 | 调用的具体模型 | `gpt-4o-mini` |
| 最大 Token 数 | 生成文章时的上限 | `4096` |
| 温度（Temperature） | 创意程度，默认 0.8 | `0.8` |

### 6.3 预设模型快捷选项

提供常见服务商的一键预填（用户只需填 API Key）：

| 服务商 | Base URL | 推荐模型 |
|--------|----------|---------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 阿里 DashScope | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 月之暗面 | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 本地 Ollama | `http://localhost:11434/v1` | `llama3` |

### 6.4 配置验证

用户填写完毕后，点击「验证连接」按钮：
- 发送一个最小测试请求（让模型返回一个单词）
- 验证成功 → 绿色提示「连接成功，模型可用」
- 验证失败 → 红色提示具体错误（Key 无效 / 网络不通 / 模型不存在）

### 6.5 无配置时的降级策略

用户未配置模型时：
- 内置词库：展示已预生成的文章（系统用官方 Key 预生成，存于数据库）
- 自定义词库：提示「请先配置 AI 模型才能生成自定义课程」，附配置入口
- 词典查词：内置词库词典数据已预存，无需实时调用

## 8. 异常与边界处理

| 场景 | 处理方式 |
|------|---------|
| AI 生成失败（网络超时） | 显示错误，提供「重试」按钮，最多自动重试 3 次 |
| API Key 无效 | 生成时检测到 401 错误，引导用户去设置页重新配置 |
| 导入词汇全部无效 | 提示「未识别到有效词汇，请检查格式」，附格式示例 |
| 词汇量不足 10 词 | 提示「词汇量过少，建议至少导入 50 个词汇」 |
| 生成途中用户离开 | 后台继续生成，完成后显示通知 |
| TTS 不支持的浏览器 | 降级：隐藏朗读按钮，提示「当前浏览器不支持语音功能」 |
| 离线状态 | 已读文章的本地缓存仍可阅读；生成功能不可用 |
| 文章加载失败 | 提示错误 + 刷新按钮，不影响其他文章 |
