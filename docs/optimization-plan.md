# 词境 WordScape 体验优化计划

> 创建时间：2026-07-26
> 文档定位：MVP（阶段 0–6）完成后的体验优化与功能补强计划，接替 `development-plan.md` 中"阶段 7 打磨与验证"，作为后续开发的执行依据。
> 更新规则：每完成一个批次，必须先更新本文档的任务勾选和变更记录，再进入下一批次开发。

---

## 一、背景与总体判断

MVP 已跑通两条核心链路（内置课程阅读 / 自定义词库生成），阅读器的"点句朗读 + 目标词高亮 + 词典卡片"核心手感已成立。

当前版本的共性问题：**每条链路都"能演示"但"不闭环"**——

- 词能收藏但没有任何地方可以查看和复习；
- 进度能记录但重新进入文章无法回到上次位置；
- 课程能生成但过程同步阻塞、不能离开页面、结果只能存一份；
- 读完一篇没有任何"我记住了吗"的反馈。

本计划的目标：把已有承诺兑现（P0）→ 让学习效果可感知（P1）→ 增加留存与增长钩子（P2）。

## 二、优化原则

1. **闭环优先于新功能**：先修断点，再谈增强。
2. **学习价值优先于虚荣指标**：先做小测/复习，后做统计图表。
3. **省用户的钱和时间**：生成链路先试读一篇再全量；等待必须可离开、可恢复。
4. **精读感优先**：默认弱化中文依赖，交互鼓励用户先读英文。

## 六、批次 C：生成链路重构（P0）

**设计变化**：从"一次性同步生成全部" 改为 "**先试读一篇 → 满意后异步生成全量**"。

- [x] 后端 `POST /api/generate/preview-article`：课程规划 + 第 1 篇试读；试读结果缓存（preview_id），全量生成直接续用不重复生成。
- [x] 前端导入页流程：预览词汇 → 生成第 1 篇试读（含正文/覆盖率展示）→ 确认「继续生成全部」或「重新生成试读」；保留「跳过试读直接生成」。
- [x] 异步任务：`POST /api/generate/course-async` + 内存态任务管理器（`task_manager.py`），前端可离开页面；`wordscape:active-generation` 指针支持从课程列表页回到进度页。
- [x] 生成进度页 `/generate-progress/[taskId]`：轮询进度条 + 每篇状态（等待/生成中/完成/失败）；完成自动保存课程并跳转；task→course 映射防重复保存。
- [x] 失败处理：单篇失败不阻断其余篇目；`POST /tasks/{id}/retry` 重试失败篇目；全失败给出可读错误文案与模型配置入口；可先保存已完成篇目。
- [x] mock 模型端到端验证：试读 → 异步 → 进度 → 自动保存 → 跳转课程全链路通过；多篇拆分（150 词 → 2 篇）与坏配置失败路径通过。

**验收标准**：用 50 词词表实测——30 秒级看到第 1 篇试读；确认后离开页面再回来，进度仍在推进且最终全部生成；任一篇失败不影响其余篇目。

## 八、批次 E：学习效果闭环（P1，最重要的新功能）

### E1. 读后小测

- [ ] 读完文章后进入小测流程：从本文抽 5–8 个目标词，用**原文句子挖空**出题（把目标词从句中抠掉，四选一），干扰项从本文其他目标词中取。纯前端实现，不调 AI。
- [ ] 答题交互：即时对错反馈；答错展示正确词 + 该句中文。
- [ ] 小测结果页：本篇掌握 X/Y；答错的词一键（默认勾选）加入生词本。
- [ ] 文章"完成"状态与小测挂钩：完成小测才算真正读完（阅读完成按钮改为"完成阅读并测一测"，保留"跳过小测"次级入口）。

### E2. 完成弹窗升级

- [ ] 完成弹窗从"平铺 18 个词"改为小测结果卡：掌握数、待复习数、连续天数（批次 G 上线前先隐藏）。
- [ ] 付费墙触发时机调整：读完第 5 篇的小测结果页之后（成就感峰值处）展示解锁引导。

**验收标准**：读完一篇必然经过"测一测"或明确跳过；错词自动沉淀进生词本；小测数据本地持久化（每篇记录最近一次成绩）。

## 九、批次 F：阅读体验升级（P1）

### F1. 中文对照策略反转（精读感关键）

- [ ] 默认收起全文中文对照。
- [ ] 点击句子时，在该句下方（或底部浮条）只显示**当前句**中文，随朗读句切换。
- [ ] "全文对照"改为主动开关，保留现有双栏/抽屉布局。
- [ ] 用户选择记忆到本地设置（始终显示 / 点句显示 / 隐藏）。

### F2. 朗读控制完善

- [ ] 再次点击正在朗读的句子 = 停止朗读（当前是重新播放）。
- [ ] 头部"朗读首句"按钮改为"连续朗读"：从当前句开始自动逐句朗读并同步高亮滚动，可随时暂停。
- [ ] 朗读语速设置（0.75x / 0.85x / 1.0x），本地持久化。

### F3. 查词痕迹（个性化起点）

- [ ] 非目标词双击查词后记录为"我查过的词"（本地持久化）。
- [ ] 查过的词在后续文章中以淡色下划线标记。
- [ ] 词典卡片对查过的词同样提供"加入生词本"。

**验收标准**：默认界面只有英文，点句才见中文；连续朗读可用且可暂停；查过的词跨文章有痕迹。

## 十、批次 G：留存与增长（P2）

- [ ] 每日一篇目标：首页展示"今日一篇"推荐（上次课程的下一篇）与完成状态。
- [ ] Streak 连续天数：以"完成一篇小测"为打卡条件，本地持久化，完成弹窗展示。
- [ ] 打卡分享图：小测结果页生成可保存图片（篇名、掌握词数、连续天数、产品名），用于社交传播。
- [ ] 生成参数暴露：词库导入页增加"文章难度（初/中/高）"与"故事风格"两个选项，透传后端 Prompt（后端字段已具备）。
- [ ] 词库分享链接（依赖 Supabase 持久化切换，若未就绪则顺延）：生成课程可产生只读分享链接。

**验收标准**：连续两天各读完一篇能看到 streak=2；分享图可保存且信息正确；难度/风格参数对生成结果有可感知影响。

## 十一、明确不做（本计划范围外）

| 项 | 原因 |
| --- | --- |
| 学习统计页 / 热力图 | 学习价值闭环未验证前是虚荣指标，推迟 |
| 微信登录、真实支付 | 属上线阶段工作，见 `phase6-mvp-plan.md` |
| 逐词跟读高亮（TTS word boundary） | 浏览器兼容成本高，先做连续朗读 |
| 深色模式、词汇自测独立模块 | 后续迭代 |

> 注意：付费墙当前为纯前端假墙（改 `status` 即可绕过），MVP 测意愿可接受；切换 Supabase 持久化时必须把免费/付费判定放进 RLS，不能只在 UI 层拦截（已在 `supabase-setup.md` RLS 验证清单中）。

## 十二、里程碑与验收

1. **里程碑 1（批次 A+B）**：承诺兑现版——生词本、变形词、继续阅读、多课程存储全部可用。
2. **里程碑 2（批次 C+E）**：可信可学版——生成链路试读+异步；读完有小测有沉淀。此时具备邀请 20 人内测打分的条件（对应 `phase1-requirements-v1.1.md` 的上线前置验证）。
3. **里程碑 3（批次 F+D）**：精读体验版——中文策略、连续朗读、40 篇真实内容就绪。
4. **里程碑 4（批次 G）**：留存增长版——streak、分享、生成参数。

每个里程碑完成时：更新本文档勾选与变更记录 → `pnpm lint` / `pnpm build` / 后端编译检查通过 → git 提交。
