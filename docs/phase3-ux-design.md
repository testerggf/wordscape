## 1. 设计原则

### 1.1 四条核心原则

**① 阅读优先（Reading First）**
产品的核心行为是阅读，所有 UI 设计服从于"让用户专注读文章"。
- 阅读页去除一切非必要元素
- 交互控件默认收起，按需唤出
- 颜色和排版以降低视觉疲劳为目标

**② 即时有感（Instant Feedback）**
每次有意义的交互必须在 100ms 内给出视觉反馈。
- 点词 → 立即高亮 + 弹层出现
- 点句 → 立即高亮 + 朗读开始
- 进度变化 → 即时更新，不需要刷新

**③ 进度可见（Progress Visible）**
用户随时知道自己在哪、还剩多少、今天学了什么。
- 文章内有进度条
- 课程列表有完成环形图
- 首页有今日学习摘要

**④ 移动优先（Mobile First）**
先设计 375px 手机版，再扩展到 768px 平板和 1280px PC。
所有触摸目标最小 44×44px，间距足够手指操作。

## 2. 视觉语言系统

### 2.1 色彩系统

```
主色系（深绿·专注·自然）
  --color-primary-900: #0D2B1F   极深绿，用于重要文字
  --color-primary-800: #1B4332   主色，导航背景、强调按钮
  --color-primary-700: #2D6A4F   次级按钮、激活状态
  --color-primary-100: #D8F3DC   浅绿，hover 背景、标签背景
  --color-primary-50:  #F0FAF2   极浅绿，卡片悬浮背景

中性色系（暖灰·纸质感）
  --color-neutral-50:  #FAFAF8   页面底色（略暖，非纯白）
  --color-neutral-100: #F5F0E8   阅读页背景（米黄，护眼）
  --color-neutral-200: #E8E2D9   分割线、边框
  --color-neutral-400: #9E9589   辅助文字、placeholder
  --color-neutral-700: #4A4540   次级正文
  --color-neutral-900: #1C1917   主要正文

强调色（琥珀·目标词标注）
  --color-accent-400:  #F4A261   目标词高亮底色
  --color-accent-200:  #FDDCB5   目标词高亮底色（浅版，深色模式）
  --color-accent-600:  #D4712A   目标词文字色（深色模式）

功能色
  --color-success:     #40916C   完成状态
  --color-warning:     #F4A261   提示状态（复用强调色）
  --color-error:       #C1121F   错误状态
  --color-info:        #4361EE   信息提示

深色模式映射（自动跟随系统）
  页面背景  → #0F1410
  阅读背景  → #161B18
  正文色    → #E8E2D9
  目标词高亮→ 底色 #3D2B00，文字 #F4A261
```

### 2.2 字体系统

```
英文正文（阅读器）
  首选：Lora（Google Fonts，衬线体，阅读友好）
  降级：Georgia → serif
  用途：文章英文正文，词典单词展示

中文正文
  首选：'PingFang SC'（iOS/Mac）
        'Noto Sans SC'（Android/Win，需加载）
  降级：'Microsoft YaHei' → sans-serif
  用途：中文对照、界面文字

界面标题
  英文：'DM Serif Display'（Google Fonts，优雅衬线标题）
  中文：同上中文字体，加粗
  用途：Landing 页标题、课程标题

代码/音标
  'Noto Sans Mono' → monospace
  用途：IPA 音标展示
```

## 3. 响应式布局策略

### 3.1 断点定义

```
xs:  < 480px    超小屏手机
sm:  480–767px  标准手机
md:  768–1023px 平板
lg:  1024–1279px 小屏 PC / 横屏平板
xl:  ≥ 1280px  标准 PC
```

### 3.2 各页面布局适配

| 页面 | 手机（xs/sm） | 平板（md） | PC（lg/xl） |
|------|-------------|----------|-----------|
| 首页 | 单列，堆叠 | 单列，内容居中 | 双列，左文右图 |
| 词库中心 | 单列列表 | 双列网格 | 三列网格 |
| 课程文章列表 | 单列卡片 | 双列卡片 | 双列卡片，右侧固定进度面板 |
| 阅读器 | 上下布局（英文+可折叠中文） | 上下布局，中文常显 | 左右分栏（6:4） |
| 生词本 | 单列 | 双列 | 三列 |
| 设置 | 单列 | 居中单列（max 600px） | 左侧导航 + 右侧内容 |

## 5. 核心组件规格

### 5.1 文章卡片组件（ArticleCard）

```
属性：
  title: string          文章标题
  index: number          序号（01–N）
  topic: string          话题标签
  wordCount: number      目标词数量
  readingMinutes: number 预计阅读分钟
  status: 'unread' | 'reading' | 'done' | 'locked'
  progress?: number      进行中时的百分比（0–100）

状态样式：
  unread  → 序号圆圈：空心，边框色
  reading → 序号圆圈：半填充，主色
  done    → 序号圆圈：实心绿色 + ✓
  locked  → 整卡片灰色，锁图标，点击触发付费弹层

交互：
  点击卡片 → 进入阅读器（locked 状态 → 付费弹层）
  长按卡片 → 快捷菜单（标记已读/重置进度）
```

### 5.2 词典卡片组件（DictCard）

```
触发：点击目标词 / 双击/长按普通词
关闭：点击遮罩 / 向下滑动（手机端）/ 点击 ×

手机端形式：底部抽屉（height: auto, max-height: 70vh）
PC 端形式：Popover 气泡（跟随词语位置，自动避让边界）

内容区域可滚动（内容超过高度时）
加入生词本后，按钮变为「已收藏 ✓」（绿色）
```

### 5.3 进度条组件（ProgressBar）

```
阅读器内进度条：
  位置：固定顶部，高度 3px
  颜色：--color-primary-700
  动画：滚动时实时更新，smooth transition

文章卡片内进度条：
  高度：6px，圆角
  颜色：done → success，reading → primary，locked → neutral-200
```

### 5.4 词汇高亮组件（HighlightWord）

```
目标词渲染规则：
  文章文本处理时，将目标词替换为 <mark> 标签
  <mark class="target-word" data-word="blank">blank</mark>

样式：
  background-color: var(--color-accent-400) 透明度 40%
  border-bottom: 2px solid var(--color-accent-400)
  border-radius: 3px
  cursor: pointer
  padding: 0 2px

hover 状态：
  background-color 透明度升至 70%
  transform: translateY(-1px)
  transition: all 0.15s ease

点击状态：
  background-color 透明度升至 90%
  scale: 0.97
```

### 5.5 TTS 句子高亮（ReadingSentence）

```
朗读时当前句样式：
  background-color: var(--color-primary-100)
  border-radius: 4px
  padding: 2px 4px
  transition: background-color 0.2s ease

逐词高亮（朗读跟词）：
  当前朗读词：font-weight: 600，color: primary-800
  使用 Web Speech API 的 boundary 事件驱动
```

## 6. 动效规格

### 6.1 页面过渡

```
路由切换：
  进入：fade + slideUp（translateY 16px → 0，opacity 0 → 1）
  时长：200ms，easing: ease-out
  退出：fade（opacity 1 → 0，100ms）
```

### 6.2 词典卡片弹出

```
手机端（底部抽屉）：
  进入：translateY(100%) → translateY(0)
  时长：280ms，easing: cubic-bezier(0.32, 0.72, 0, 1)
  遮罩：opacity 0 → 0.4，同步

PC 端（Popover）：
  进入：scale(0.95) + opacity(0) → scale(1) + opacity(1)
  时长：160ms，easing: ease-out
  transform-origin：靠近目标词一侧
```

### 6.3 目标词点击反馈

```
点击瞬间：scale 1 → 0.94（50ms）→ 1.02（100ms）→ 1（150ms）
背景色：快速闪烁加深（duration 100ms）
```

### 6.4 文章完成庆祝动效

```
🎉 emoji 从屏幕中央放大出现（scale 0 → 1.2 → 1，300ms）
标题文字从下方进入（translateY 20px → 0，400ms，delay 200ms）
词汇标签逐个从左淡入（stagger 50ms per tag）
```

### 6.5 生成进度动画

```
课程生成时：
  进度条：平滑增长（每完成一篇 +N%）
  已完成篇数计数：数字翻滚动画（counter animation）
  每完成一篇：卡片从右侧滑入列表
```

## 7. 无障碍设计

| 规范 | 实现方式 |
|------|---------|
| 色彩对比度 | 正文文字对比度 ≥ 4.5:1（WCAG AA） |
| 触摸目标 | 最小 44×44px（符合 Apple HIG） |
| 键盘导航 | 阅读器支持方向键翻段，空格键播放/暂停朗读 |
| 屏幕阅读器 | 目标词 `<mark>` 添加 `aria-label`，词典弹层 `role="dialog"` |
| 字体缩放 | 支持系统字体缩放（使用 rem 单位） |
| 减弱动效 | 尊重 `prefers-reduced-motion`，关闭非必要动画 |
