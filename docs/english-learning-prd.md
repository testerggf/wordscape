## 1. 产品概述

### 1.1 产品定位

**四级词汇精读平台**——用 40 篇精心构建的英文故事，打通四级 4000 词汇的记忆壁垒。

区别于"背单词 App"的孤立记忆模式，本平台以**叙事语境**为载体，将单词嵌入可读的故事中，通过分类语境、复现机制、分层引入三重设计，让用户在阅读中自然习得词汇、语法与语感。

### 1.2 核心价值主张

| 传统背单词 | 本平台 |
|------------|--------|
| 孤立单词，缺乏语境 | 词汇嵌入故事，天然语境 |
| 记了又忘，效率低下 | 复现机制对抗遗忘曲线 |
| 枯燥乏味，难以坚持 | 故事形式，可读性强 |
| 词汇、语法、语感割裂学习 | 三者同步习得 |
| 无即时反馈 | 点词查义、音标、例句即时呈现 |

### 1.3 产品一句话

> **40 篇故事，读完就过四级。**

## 2. 需求分析

### 2.1 问题定义

**核心痛点**：四级词汇量大（约 4000 词），孤立记忆效率极低，遗忘速度远超记忆速度。

**已验证的解法思路**：
- 将词汇嵌入文章语境 → 词汇+语法+语感一体化
- 控制文章参数（篇幅 ~1000 词，目标词密度 ~10%）→ 可读性与学习效率的最优平衡点
- 40 篇覆盖 4000 词（每篇 100 核心词，允许词汇复现）

**量化设计逻辑**：

```
文章篇数 = 目标词汇量 ÷ 每篇核心词数
         = 4000 ÷ 100
         = 40 篇

每篇长度 = 1000 词
目标词密度 = 100 / 1000 = 10%
（其余 90% 为已知词汇或高频词，保证可读性）
```

### 2.2 三重学习设计

#### ① 分类法（语境记忆）
按话题聚类，同一语义场的词汇同时出现，形成记忆网络：

| 话题分类（示例） | 代表词汇方向 |
|-----------------|-------------|
| 校园生活 | academic, semester, curriculum, assignment... |
| 职场与经济 | enterprise, negotiate, budget, efficiency... |
| 文化与旅游 | heritage, authentic, itinerary, landmark... |
| 科技与创新 | innovation, algorithm, sustainable, digital... |
| 健康与生活 | nutrition, therapy, symptom, resilience... |

#### ② 复现法（对抗遗忘）
新文章中有意引入前文出现过的词汇，利用间隔重复原理强化记忆，每个核心词平均在 3 篇以上文章中出现。

#### ③ 分层法（高频优先）
前 10 篇大量引入最高频词汇（4 级词中的 Top 500），奠定阅读基础；后续篇章逐步引入中低频词，学习曲线平滑。

### 2.3 功能需求来源

```
内容体系（已设计好）→ 数字化呈现工具
                    → 中英文对照阅读
                    → 点句听读
                    → 点词查义（音标、释义、词根、例句）
                    → 学习进度追踪
                    → 移动端友好（随时随地碎片化学习）
```

## 4. 核心内容体系

### 4.1 文章规格标准

```
篇幅：800–1200 词（目标 1000 词）
核心四级词：每篇 80–120 个（目标 100 个）
目标词密度：约 10%
可读性：其余词汇以高频词和简单词为主
体裁：叙事故事（narrative），避免论说文
配套：中文全文翻译、逐句对照
```

### 4.2 40 篇文章规划（话题分布）

| # | 话题大类 | 文章数 | 核心词汇方向 |
|---|---------|--------|------------|
| 1–5 | 校园生活 | 5 篇 | 学习、社团、考试、宿舍、毕业 |
| 6–10 | 个人成长 | 5 篇 | 目标、压力、习惯、心理、自信 |
| 11–15 | 职场与经济 | 5 篇 | 求职、团队、商业、薪资、创业 |
| 16–20 | 科技与创新 | 5 篇 | 互联网、人工智能、环境、能源、发明 |
| 21–25 | 文化与旅游 | 5 篇 | 传统、艺术、语言、旅游、饮食 |
| 26–30 | 健康与生活 | 5 篇 | 医疗、运动、饮食、心理健康、家庭 |
| 31–35 | 社会与时事 | 5 篇 | 教育、环保、法律、媒体、城市化 |
| 36–40 | 综合复现篇 | 5 篇 | 覆盖高遗忘词汇，跨话题综合场景 |

> 第 36–40 篇为"复现强化篇"，专门引入前 35 篇中统计遗忘率最高的词汇，确保全覆盖。

### 4.3 单词数据结构（每个核心词包含）

- 单词本身（word）
- 音标（IPA phonetic）
- 词性（pos）
- 中文释义（definition_zh，1–3 条）
- 英文释义（definition_en）
- 词根词缀（etymology，可选）
- 例句（examples，2–3 句，含中文翻译）
- 词频等级（frequency_rank）
- 所属话题（topic_tags）
- 出现篇章列表（appears_in）

### 5.2 核心交互详细规格

#### 阅读页交互

```
布局模式（手机）：
  上方：英文原文（主视图）
  下方：中文对照（可折叠）

布局模式（PC）：
  左栏：英文原文
  右栏：中文对照

交互：
  - 点击英文句子 → 该句高亮 + TTS 朗读该句
  - 双击/长按英文单词 → 弹出词典浮层
  - 核心词默认标色（如底部浅黄色下划线）
  - 滑动阅读，顶部显示阅读进度条

词典浮层规格：
  触发：双击单词
  位置：单词上方或屏幕下方弹出（根据位置动态判断）
  内容：
    ① 单词 + 音标（含 🔊 发音按钮）
    ② 词性 + 中文释义
    ③ 词根（可折叠）
    ④ 例句 1–2 条
    ⑤ [加入生词本] 按钮
  关闭：点击空白区域
```

#### 文章列表页

```
展示：
  - 卡片式列表，每张卡片含：
    · 序号（01–40）
    · 话题标签
    · 文章标题
    · 核心词数量
    · 阅读状态（未读/进行中/已读）
    · 预计阅读时间（约 8 分钟）
  
  - 顶部话题筛选标签栏（横向滚动）
  - 整体进度环形图（已读/总篇数）
```

## 7. 页面设计规格

### 7.1 设计原则

- **移动优先**：所有页面以 375px 宽度为基准设计，适配至 768px（Pad）和 1280px（PC）
- **沉浸阅读**：阅读页去除干扰元素，以内容为核心
- **即时反馈**：每次交互（点词、点句）必须有视觉+听觉双反馈
- **进度可见**：用户随时感知自己的学习进度

### 7.2 视觉风格

| 元素 | 规格 |
|------|------|
| 主色 | 深墨绿 `#1B4332`（专注、自然） |
| 辅色 | 暖米黄 `#F5F0E8`（纸质感背景） |
| 强调色 | 琥珀黄 `#F4A261`（核心词标注） |
| 字体（英文正文） | Georgia / Lora（衬线体，阅读友好） |
| 字体（界面文字） | PingFang SC / Noto Sans SC |
| 正文字号（手机） | 英文 17px，中文 15px |
| 行高 | 1.8（保证阅读舒适度） |
