## 一、产品方向

词境 WordScape 是一个 AI 驱动的词汇精读产品。它的核心不是机械背单词，而是把词汇表转化为可阅读、可复现、可查词、可听读的故事课程。

MVP 需要验证两条核心链路：

1. 内置四级阅读链路：课程列表 → 阅读器 → 目标词高亮 → 词典卡片 → 句子朗读 → 生词本 → 免费篇章后的付费墙。
2. 自定义词库生成链路：模型配置 → 词汇导入 → 课程预览 → AI 生成 → 进度跟踪 → 进入生成课程阅读。

## 二、实施策略

先用本地种子数据做出可见、可交互的阅读体验，再接后端和持久化。这样可以避免早期开发被 Supabase 配置、API Key、正式生成内容阻塞。

开发优先级：

1. 先验证阅读体验是否成立。
2. 再补学习闭环和基础商业闭环。
3. 再做 AI 生成流水线。
4. 最后接 Supabase、认证、权限和生产数据。
