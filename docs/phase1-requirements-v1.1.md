# Phase 1 · 需求分析文档（修订版 v1.1）

> **项目名称**：词境（WordScape）—— AI 驱动的词汇精读平台
> **文档版本**：v1.1（新增词汇导入 & AI 文章生成能力）
> **阶段**：需求分析

---

## 一、问题定义

### 1.1 核心问题

无论是备考四六级的学生、准备中高考的青少年，还是备考雅思托福的职场人，都面临同一个根本矛盾：

> **需要在有限时间内记住大量指定词汇，但孤立的单词缺乏语境连接，记忆效率极低——边记边忘，形成恶性循环。**

这个问题的本质不是"词汇量不够"，而是**记忆的组织方式出了问题**。大脑对孤立信息的留存率远低于有语境、有情节的信息。

### 1.2 现有方法的缺陷

| 方法 | 代表产品 | 核心问题 |
|------|---------|---------|
| 单词 App 刷词 | 墨墨、扇贝 | 词汇孤立，缺乏语境；机械重复，容易厌倦 |
| 背单词书 | 红宝书、乱序版 | 同上，纸质形式缺乏即时反馈 |
| 刷真题/阅读 | 各类题库 | 词汇密度低；题目导向，阅读体验差 |
| 看美剧/原著 | Netflix、Kindle | 词汇太难，挫败感强；针对性差 |
| 泛读英文文章 | 各类新闻网站 | 缺乏系统性；无法对准特定词汇表 |

**所有现有方法的共同缺陷**：无法同时满足"针对特定词汇表 × 可读性强 × 系统复现"三个条件。

### 1.3 本产品的解法

用 **AI 自动生成的精读文章** 承载任意用户指定的词汇表：

- 系统内置四级、六级词汇表，开箱即用
- 支持导入任意词汇表（初中、高中、考研、雅思、托福、行业词汇……）
- AI 按照严格参数生成故事文章：1000 词、10% 目标词密度、话题分类、复现机制
- 每篇文章配套中文对照、TTS 朗读、逐词词典

**这意味着产品从"固定内容平台"升级为"AI 内容生成引擎"**，内容边界无限扩展。

### 2.3 产品一句话

> **输入词汇表，AI 生成故事，读完就记住。**

## 三、核心学习方法论

### 3.1 文章生成的黄金参数

```
篇幅：约 1000 词/篇
目标词密度：10%（每篇含 100 个目标词汇）
可读性要求：其余 90% 词汇为高频易懂词
体裁：叙事故事（narrative），避免论说文
语言难度：根据词汇表等级自动调整句式复杂度
```

**为什么是 10% 密度？**

```
密度 < 5%  → 效率过低，1000词只遇到50个目标词
密度 10%   → 黄金区间：每句约1个新词，流畅可读
密度 > 15% → 可读性崩溃，读起来像在硬啃词汇表
```

**篇数计算公式：**

```
最少篇数 = 词汇表总量 ÷ 每篇目标词数(100)
示例：
  初中词汇（1500词）→ 最少 15 篇
  高中词汇（3500词）→ 最少 35 篇
  四级词汇（4000词）→ 最少 40 篇
  六级词汇（6000词）→ 最少 60 篇
  考研词汇（5500词）→ 最少 55 篇
```

### 3.2 三重学习设计机制

#### ① 分类法（语境记忆）
AI 生成文章前，先对词汇表进行话题聚类，同一语义场的词汇在同一篇文章中集中出现，形成记忆网络。

**内置话题分类（可扩展）：**

| 话题类别 | 词汇方向示例 |
|---------|------------|
| 校园生活 | academic / semester / curriculum / assignment |
| 个人成长 | ambition / discipline / resilience / motivation |
| 职场与经济 | enterprise / negotiate / efficient / investment |
| 科技与创新 | innovation / algorithm / sustainable / patent |
| 文化与旅游 | heritage / authentic / itinerary / cuisine |
| 健康与生活 | nutrition / therapy / symptom / diagnosis |
| 社会与时事 | policy / equality / legislation / urban |
| 自然与环境 | ecosystem / pollution / renewable / biodiversity |

#### ② 复现法（对抗遗忘）
AI 在生成后续文章时，自动将前文出现过的词汇引入新文章，核心词平均复现 3–5 次。

```
复现规则（系统自动执行）：
  高频词（Top 25%）→ 至少复现 5 次，分布在不同话题篇章
  中频词（25–75%）→ 至少复现 3 次
  低频词（Bottom 25%）→ 至少复现 2 次
```

#### ③ 分层法（高频优先）
系统对词汇表按频率排序，前期篇章大量引入高频词，后期逐步引入低频词，学习曲线平滑。

```
课程结构示例（40篇四级课程）：
  第 1–10 篇 → 词频 Top 25%（约1000词）为主
  第 11–25 篇 → 词频 25–75%（约2000词）为主 + 高频词复现
  第 26–35 篇 → 词频 Bottom 25%（约1000词）为主 + 中频词复现
  第 36–40 篇 → 综合复现篇，专攻遗忘率最高的词汇
```

## 四、用户画像

### 4.1 用户分层

```
个人用户
├── 学生群体
│   ├── 初中生（中考词汇）
│   ├── 高中生（高考词汇）
│   ├── 大学生（四级 / 六级）
│   └── 考研生（考研词汇）
├── 职场人群
│   ├── 雅思/托福备考（出国/移民）
│   └── 行业英语提升（医疗、法律、IT等）
└── 兴趣学习者（自定义导入）

机构用户（未来扩展）
├── 学校教师（导入教材词汇，为班级生成课程）
└── 培训机构（定制化词汇课程）
```

### 4.2 主要用户 A：四六级备考大学生

| 属性 | 描述 |
|------|------|
| 年龄 | 18–22 岁 |
| 目标 | 通过四级或六级 |
| 设备 | 手机为主，偶尔 PC |
| 使用场景 | 课间、通勤、睡前，碎片化 10–30 分钟 |
| 痛点 | 单词记不住；背单词太枯燥；不知道还差多少 |
| 付费意愿 | 低至中（备考期集中付费意愿强） |
| 获客渠道 | 大学生社区、B站、小红书 |

### 4.3 主要用户 B：高中生（家长付费）

| 属性 | 描述 |
|------|------|
| 年龄 | 15–18 岁（决策人是家长） |
| 目标 | 提高高考英语成绩，掌握高考词汇 |
| 设备 | 手机（受管控）、iPad、PC |
| 痛点 | 词汇量不够；阅读理解差；家长希望有系统方法 |
| 付费意愿 | 高（教育类家长付费意愿强） |
| 获客渠道 | 家长社群、学而思等教育平台联动 |

### 4.4 次要用户 C：职场英语提升者

| 属性 | 描述 |
|------|------|
| 年龄 | 22–35 岁 |
| 目标 | 雅思/托福备考，或职场英语提升 |
| 设备 | 手机 + PC 并用 |
| 痛点 | 没时间系统学；词汇量停滞；行业词汇缺乏 |
| 付费意愿 | 中至高 |
| 获客渠道 | LinkedIn、职场社群、雅思论坛 |

### 4.5 潜力用户 D：教师/机构（B 端）

| 属性 | 描述 |
|------|------|

## 五、词汇导入功能规格

### 5.1 支持的导入方式

| 导入方式 | 说明 | 优先级 |
|---------|------|--------|
| 系统内置词库选择 | 四级/六级/初中/高中/考研/雅思等 | Must |
| 文本粘贴导入 | 直接粘贴单词列表（每行一词或逗号分隔） | Must |
| TXT/CSV 文件上传 | 上传本地词汇文件 | Should |
| 图片/PDF 扫描识别 | 拍照词汇表，OCR 识别 | Could |
| 分享链接导入 | 他人分享词库链接，一键导入 | Could |

### 5.2 内置词库列表

| 词库名称 | 词汇量 | 适用人群 | 预计生成篇数 |
|---------|--------|---------|------------|
| 初中英语词汇 | ~1500 词 | 初中生 | 15 篇 |
| 高中英语词汇（新课标） | ~3500 词 | 高中生 | 35 篇 |
| 大学英语四级词汇 | ~4000 词 | 大学生 | 40 篇 |
| 大学英语六级词汇 | ~6000 词 | 大学生 | 60 篇 |
| 考研英语词汇 | ~5500 词 | 考研生 | 55 篇 |
| 雅思核心词汇 | ~4500 词 | 雅思备考 | 45 篇 |
| 托福核心词汇 | ~4000 词 | 托福备考 | 40 篇 |

### 5.3 导入词汇的处理流程

```
用户导入词汇表
      ↓
系统去重 & 清洗（去掉空格、大小写统一、过滤非英语词）
      ↓
词汇频率评级（调用词频数据库，标注每个词的使用频率）
      ↓
话题聚类（AI 将词汇按语义话题自动分组）
      ↓
生成课程结构（确定篇数、每篇话题、词汇分配）
      ↓
逐篇 AI 生成文章（含复现词注入）
      ↓
生成词典数据（音标、释义、词根、例句）
      ↓
课程上线，用户开始学习
```

### 5.4 生成时间预估

| 词汇量 | 生成篇数 | 预计生成时间 |
|--------|---------|------------|
| ~1500 词 | 15 篇 | 约 2–3 分钟 |
| ~4000 词 | 40 篇 | 约 5–8 分钟 |
| ~6000 词 | 60 篇 | 约 8–12 分钟 |

> 生成为异步任务，用户提交后可离开，生成完成后推送通知。
