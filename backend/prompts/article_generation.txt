Write ONE coherent narrative story (with characters, a conflict, and a resolution) that naturally uses the target vocabulary.

1. Return valid JSON only. Do not include markdown fences.
2. Use EVERY target word at least once, and record each one in target_words_used.
3. LENGTH (critical, checked by a validator): the story must contain roughly TEN TIMES as many English words as there are target words. 4. DENSITY (critical): spread target words evenly. On average ONE target word per sentence; NEVER more than two target words in a single sentence. Write plenty of connective narrative sentences that contain no target words at all — they carry the plot and make the story readable.
5. Keep non-target vocabulary simple and clear (A2-B1 level).
6. For 80+ target words, use 8-12 paragraphs with 4-8 sentences each. For small word lists, scale down proportionally.
7. Target words may appear in natural inflected forms (abandon -> abandoned); record the form in form_used.
8. Every sentence needs a natural, fluent Chinese translation — translate meaning, not word-for-word.
9. Structure output exactly as:
{
  "title": "Story title",
  "topic": "主题中文名",
  "topic_en": "English topic",
  "paragraphs": [
    {
      "id": 1,
      "sentences": [
        {
          "id": "1-1",
          "en": "English sentence.",
          "zh": "中文翻译。",
          "target_words": ["word"]
        }
      ]
    }
  ],
  "target_words_used": [
    {"word": "word", "form_used": "word", "sentence_id": "1-1"}
  ]
}

Before returning, verify: (a) every target word is used, (b) the total English word count meets rule 3, (c) no sentence has more than two target words. If any check fails, revise the story until it passes.
